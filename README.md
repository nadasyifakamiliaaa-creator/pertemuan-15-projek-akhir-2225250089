# Aplikasi Analisis Nilai Siswa

## Deskripsi
Program untuk menghitung dan menganalisis nilai siswa.

## Fitur
- Input nilai siswa
- Menghitung rata-rata
- Menentukan kelulusan
- Menampilkan nilai minimum dan maksimum
- Menampilkan ringkasan hasil

## Persyaratan
- Python 3.x
- Visual Studio Code

## Cara Menjalankan
python main.py

## Struktur Folder
- main.py : Program utama
- src/input_data.py : Input nilai
- src/proses.py : Proses perhitungan
- src/output.py : Menampilkan hasil
- tests/test_case.md : Pengujian program
